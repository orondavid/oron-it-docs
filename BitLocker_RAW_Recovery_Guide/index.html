    מדריך: טיפול בדיסק שהפך ל־RAW לאחר הסרת BitLocker (CMD בלבד + TestDisk)

    מדריך מלא לעבודה בסביבת WinRE כאשר Windows אינו עולה, והגישה היחידה היא דרך CMD בלבד.

    חלק 1 – אבחון הבעיה דרך CMD בלבד

    1.1 פתיחת DiskPart ובדיקת דיסקים

    diskpart
list disk
list volume

    מה לחפש?

    • מחיצה שמופיעה כ־RAW
    • מחיצה בגודל תקין אך ללא File System
    • מחיצה שמופיעה בלי אות כונן

    1.2 בדיקת מצב BitLocker (אם רלוונטי)

    manage-bde -status

    וודא: - Fully Decrypted
    - No Protectors
    - Percentage Encrypted = 0%

    אם BitLocker כבר הוסר — הבעיה במחיצה, לא בהצפנה.

    1.3 ניסיון להציג את המחיצה

    נסה לתת אות כונן:

    select volume X
assign letter=Z

    אם עדיין RAW → מערכת הקבצים פגומה.

    חלק 2 – פעולות תיקון דרך CMD (ללא כלים חיצוניים)

    2.1 ניסיון תיקון Boot Sector

    bootrec /fixboot
bootrec /fixmbr
bootrec /scanos
bootrec /rebuildbcd

    תוצאות אפשריות: - אם המחיצה מזוהה → ה-Bootloader תוקן. - אם לא מזוהה → בעיית GPT/NTFS.

    2.2 בדיקת מחיצות GPT

    diskpart
sel disk 0
detail disk

    אם כתוב: - GPT: Yes → מערכת GPT
    - GPT: No → MBR

    2.3 ניסיון לשחזר EFI (אם Windows לא עולה)

    diskpart
sel disk 0
list vol
sel vol X  (מחיצת EFI, בדרך כלל 100–300MB)
assign letter=S
exit

    שחזור קבצי EFI:

    bcdboot C:\Windows /s S: /f UEFI

    אם מצליח → ה-Bootloader תוקן.

    2.4 בדיקת NTFS (רק אם NOT RAW!)

    chkdsk Z: /f

    ⚠️ לא להריץ chkdsk על RAW — עלול לפגוע במידע.

    חלק 3 – שחזור מלא באמצעות TestDisk (כלי חיצוני מתוך CMD)

    כאשר המחיצה RAW — Windows לא יכול לשקם אותה רק עם פקודות מובנות.

    לכן משתמשים ב־TestDisk שמריצים דרך USB מה־CMD.

    3.1 הרצת TestDisk מתוך USB

    1. הורד TestDisk:
      https://www.cgsecurity.org/wiki/TestDisk_Download

    2. העתק ל־USB.

    3. חבר USB וב-WinRE הרץ: 

      E:\testdisk_win.exe
      או האות המתאימה.

    3.2 סריקת מחיצות

    בחר: 

    Create
Select Disk (לפי הגודל)
EFI GPT
Analyse
Quick Search

    TestDisk יזהה מחיצות שנעלמו.

    3.3 הצגת קבצים מתוך CMD ב-TestDisk

    סמן את המחיצה הרלונטית (NTFS המקורי):

    P

    אם אתה רואה את הקבצים → המידע קיים במלואו.

    3.4 שחזור GPT/MBR

    אם המחיצה תקינה:

    Write

    TestDisk ישחזר את מבנה המחיצה המקורי מבלי לפגוע בנתונים.

    הפעל מחדש את המחשב.

    חלק 4 – בדיקה לאחר התיקון

    4.1 בדיקת מחיצות מחדש

    diskpart
list volume

    המחיצה אמורה להיות: - NTFS - עם אות כונן תקינה

    4.2 בדיקה שהדיסק עלה תקין

    אם זו מחיצת מערכת: - Windows אמור לעלות רגיל - כל הקבצים אמורים להימצא

    חלק 5 – טיפים חשובים

    • לעולם לא לבצע פורמט למחיצת RAW אם הנתונים חשובים.
    • לא להריץ chkdsk על RAW.
    • TestDisk הוא הכלי הבטוח ביותר לתיקון metadata.
    • לאחר השחזור מומלץ לבצע גיבוי מלא.

    סיכום

    • הפקודות של CMD מאפשרות לתקן Bootloader, EFI, ולזהות בעיות.
    • אם המחיצה הפכה ל־RAW — רק שחזור טבלת מחיצות או NTFS metadata יחזיר אותה.
    • TestDisk מאפשר לבצע שחזור מלא מתוך CMD ללא צורך ב-Windows תקין.

    המדריך כולל את כל השלבים הדרושים להתמודדות מלאה עם הבעיה כאשר Windows אינו עולה כלל.
