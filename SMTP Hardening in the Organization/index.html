    הקשחת SMTP בארגון

    מסמך זה מרכז את עקרונות ההקשחה, ההגדרות והבדיקות הנדרשות להקשחת פרוטוקול SMTP בארגון, בסביבה העובדת עם:

    • משתמשים דרך Outlook (אפליקציה)
    • משתמשים דרך Outlook Web (OWA)
    • סורקים / מדפסות / מערכות אוטומטיות
    • משתמש ייעודי לשליחת דוא"ל (Service Account)

    1. מטרות ההקשחה

    • מניעת שליחת Spam ו-Malware מתוך הארגון
    • חסימת SMTP לא מאובטח
    • צמצום משטח תקיפה (Attack Surface)
    • הפרדת משתמשים רגילים מחשבונות שירות
    • עמידה ב-Best Practices של Microsoft וארגוני אבטחה

    2. הקשחה ברמת הרשת (Firewall)

    2.1 חסימות חובה

    • חסימת Outbound TCP 25 לכל היעדים באינטרנט
    • חסימת SMTP ללא הצפנה (Plain SMTP)

    2.2 פתיחות נדרשות

    • Outbound TCP 587 לשרתי Microsoft 365 בלבד
    • Outbound TCP 443 (Outlook / OWA / Modern Auth)

    2.3 המלצות נוספות

    • הגבלת 587 ל-FQDN / IPs של Microsoft בלבד
    • ניטור ניסיונות יציאה על פורט 25

    3. הקשחה ב-Microsoft 365 / Exchange Online

    3.1 משתמשים רגילים (Outlook / Web)

    • SMTP AUTH: Disabled
    • שליחת דוא"ל דרך Outlook בלבד
    • MFA מופעל (Conditional Access)
    • ללא שימוש בפרוטוקול SMTP ישיר

    3.2 משתמש ייעודי לסורקים (Service Account)

    • SMTP AUTH: Enabled (רק למשתמש זה)
    • פורט: 587 בלבד
    • הצפנה: STARTTLS חובה
    • ללא MFA
    • ללא גישת Outlook / OWA
    • ללא הרשאות אדמין
    • ללא רישוי מיותר (רק אם נדרש בפועל)

    4. סורקים / מדפסות / מערכות אוטומטיות

    תצורה מאושרת

    • SMTP Server: smtp.office365.com
    • Port: 587
    • Encryption: STARTTLS
    • Authentication: משתמש ייעודי בלבד

    תצורות אסורות

    • שליחה ישירה לאינטרנט
    • שימוש בפורט 25
    • שימוש במשתמש רגיל
    • שליחה ללא הצפנה

    5. הצפנה ו-TLS

    • אכיפת TLS 1.2 ומעלה בלבד

    • ביטול:

    • SSL

    • TLS 1.0
    • TLS 1.1
    • אין לאפשר SMTP ללא הצפנה בשום תרחיש

    6. הגנה מפני זיוף (Anti-Spoofing)

    חובה להגדיר בדומיין:

    • SPF – כולל Microsoft 365 בלבד
    • DKIM – מופעל
    • DMARC – לפחות p=quarantine, מומלץ p=reject

    ללא סעיף זה – ההקשחה הפנימית אינה מספקת.

    7. ניטור, בקרה והתראות

    • כשלי SMTP AUTH
    • ניסיונות יציאה על פורט 25
