    מדריך מלא: מיגרציה מ־VMware ל־Proxmox (שלב־אחר־שלב)

    מדריך זה מסכם בצורה רציפה, נקייה וללא כפילויות את כל התהליך שבוצע: - הכנת דיסק פיזי - הגדרת Storage - העתקת VMDK - המרה ל־RAW - חיבור ל־VM - התקנת VirtIO - מעבר מ־SATA ל־SCSI - פתרון תקלות Boot / CPU / ביצועים

    המדריך מותאם לפרסום באתר תיעוד (Markdown).

    פרק 1 – עקרונות יסוד (לפני שמתחילים)

    1.1 סוגי Storage ב־Proxmox

    Storage סוג שימוש מומלץ
    local Directory ISO, Backups, Templates
    local-lvm LVM-thin VMים (Block) – לא חובה
    data Directory (ext4/xfs) VMים, Import, Nakivo, עבודה ידנית
    data-lvm LVM-thin אופציונלי בלבד

    הבחירה במדריך:

    כל ה־VMים יושבים על data (Directory, ext4)

    1.2 Block vs File (הבנה קריטית)

    • LVM / ZFS → דיסק VM הוא בלוק (לא רואים קובץ)
    • EXT4 / XFS → דיסק VM הוא קובץ (raw / qcow2)

    למה בחרנו File-based? - קל לייבוא מ־VMware - נוח לגיבוי (Nakivo / PBS) - קל להעברה / בדיקה / שחזור

    פרק 2 – הכנת דיסק פיזי ל־data

    2.1 זיהוי הדיסק

    lsblk

    בדוגמה: 

    sdb  3.3T  disk
└─sdb1 3.3T part

    2.2 יצירת GPT + מחיצה

    apt update && apt install -y parted
parted /dev/sdb --script mklabel gpt
parted /dev/sdb --script mkpart primary 0% 100%

    2.3 יצירת מערכת קבצים

    mkfs.ext4 /dev/sdb1

    2.4 Mount קבוע

    mkdir -p /mnt/data
blkid /dev/sdb1

    עריכת fstab: 

    nano /etc/fstab

    הוספה: 

    UUID=XXXX-XXXX  /mnt/data  ext4  defaults  0  2

    בדיקה: 

    mount -a
df -h /mnt/data

    פרק 3 – הוספת Storage ל־Proxmox

    pvesm add dir data \
  --path /mnt/data \
  --content images,iso,backup,import

    בדיקה ב־GUI:

    Datacenter → Storage → data

    פרק 4 – העתקת קבצי VMware

    4.1 מבנה תיקיות

    mkdir -p /mnt/data/images/100

    4.2 העתקת VMDK

    באמצעות WinSCP / SCP: 

    Dev.vmdk → /mnt/data/images/100/

    פרק 5 – המרת VMDK ל־RAW

    qemu-img convert -p -f vmdk -O raw \
  /mnt/data/images/100/Dev.vmdk \
  /mnt/data/images/100/vm-100-disk-0.raw

    בדיקה: 

    ls -lh /mnt/data/images/100

    פרק 6 – יצירת VM (שלד בלבד)

    ב־GUI: - BIOS: OVMF (UEFI) - Machine: q35 - Disk: קטן זמני (או ללא) - OS Type: Windows 10/11

    פרק 7 – חיבור הדיסק המומר ל־VM

    7.1 חיבור דרך CLI (מומלץ)

    qm set 100 -scsi0 data:100/vm-100-disk-0.raw

    בדיקה: 

    qm config 100

    7.2 למה לא דרך Add Disk?

    • Add Disk → יוצר דיסק חדש
    • Import Disk → מייבא ל־LVM
    • Attach קובץ קיים → רק CLI או Unused Disk

    פרק 8 – התקנת VirtIO Drivers

    8.1 הורדה

    להוריד: 

    virtio-win.iso

    8.2 חיבור ISO

    VM → Hardware → CD/DVD → Mount ISO

    8.3 התקנה בתוך Windows

    להריץ: 

    virtio-win-guest-tools.exe

    כולל: - Storage - Network - Balloon - QEMU Agent

    לאחר ההתקנה → Restart

    פרק 9 – מעבר מ־SATA ל־SCSI (VirtIO)

    שלב 1 – הוספת דיסק VirtIO קטן (דמה)

    VM → Add → Hard Disk → SCSI → 3GB

    שלב 2 – עליית Windows

    בדיקה ב־Device Manager: - Red Hat VirtIO SCSI Controller

    שלב 3 – כיבוי VM

    שלב 4 – ניתוק דיסק SATA

    GUI → Detach (לא Delete)

    שלב 5 – חיבור מחדש כ־SCSI

    qm set 100 -scsi1 data:100/vm-100-disk-0.raw

    שלב 6 – Boot Order

    להגדיר: 

    scsi1 ראשון

    פרק 10 – פתרון תקלות נפוצות

    10.1 INACCESSIBLE_BOOT_DEVICE

    סיבה: - מעבר ל־SCSI בלי VirtIO

    פתרון: - דיסק דמה - התקנת דרייבר - רק אז מעבר

    10.2 CPU 100%

    פתרון: - CPU type: host - Cores: 4 - התקנת VirtIO

    qm set 100 -cpu host -cores 4

    10.3 שינוי CPU תוך כדי עבודה?

    פעולה דורש כיבוי
    שינוי cores כן
    שינוי cpu type כן

    פרק 11 – תצוגה (Display)

    מומלץ: - Display: Default או SPICE - אין צורך בדרייבר GPU

    VirtIO-GPU → רק לשימושים גרפיים מיוחדים

    פרק 12 – סיכום Best Practice

    ✔ דיסקי VM → data (ext4) ✔ פורמט דיסק → raw ✔ Controller → VirtIO SCSI single ✔ CPU → host ✔ תמיד להתקין VirtIO לפני מעבר ✔ לא למחוק VMDK לפני שה־VM עולה
