    הקדמה

    Graylog הוא כלי מתקדם לניהול לוגים ובקרה ארגונית. המדריך הזה מבוסס על ניסיון אמיתי, כולל כל הבעיות ופתרונן בתהליך התקנה על Ubuntu Server.

    דרישות מקדימות

    • Ubuntu 22.04/20.04 (עדכני ומעודכן)
    • שרת ייעודי/VM עם: 4GB RAM (לפחות, מומלץ 8GB+), 2 vCPU, 20GB+ דיסק.
    • חיבור אינטרנט
    • הרשאות root/sudo

    הכנת שרת Ubuntu

    • עדכן חבילות:

    sudo apt update && sudo apt upgrade -y
sudo apt install apt-transport-https openjdk-17-jre-headless pwgen curl -y
    * בדוק גרסת Java:

    java -version
# הפלט צריך לכלול OpenJDK 17

    התקנת MongoDB

    • התקן מ־repo:

    wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list
sudo apt update
sudo apt install -y mongodb-org
sudo systemctl enable mongod --now
sudo systemctl status mongod
    * בדוק:

    sudo systemctl status mongod

    התקנת Opensearch

    • הורד והתקן גרסה עדכנית (בדוק ב-site הרשמי):

    wget https://artifacts.opensearch.org/releases/bundle/opensearch/2.19.2/opensearch-2.19.2-linux-x64.deb
sudo dpkg -i opensearch-2.19.2-linux-x64.deb
    * וודא הרשאות:

    sudo chown -R opensearch:opensearch /etc/opensearch /var/lib/opensearch /var/log/opensearch
    * פתח את קובץ ההגדרות:

    sudo nano /etc/opensearch/opensearch.yml
    * לסביבת בדיקות בלבד (לעקוף בעיית SSL): הוסף בסוף הקובץ:

    plugins.security.disabled: true
    * הפעל את השירות:

    sudo systemctl enable opensearch --now
sudo systemctl status opensearch
    * בדוק חיבור:

    curl -XGET 'localhost:9200'
# אמור להחזיר JSON של Opensearch

    התקנת Graylog

    • הורד והתקן גרסה עדכנית מ־Deb:

    wget https://packages.graylog2.org/repo/packages/graylog-5.2-repository_latest.deb
sudo dpkg -i graylog-5.2-repository_latest.deb
sudo apt update && sudo apt install graylog-server -y
    * ודא שכל התלויות מותקנות (java, pwgen, וכו').

    הגדרות קריטיות: הרשאות ותיקונים

    • ודא הרשאות תקינות לתיקיות (כל תיקיה ותתי-הספריות):
    sudo chown -R opensearch:opensearch /etc/opensearch /var/lib/opensearch /var/log/opensearch
sudo chown -R graylog:graylog /etc/graylog /var/log/graylog-server

    פתרון בעיות נפוצות (Troubleshooting)

    • שגיאות הרשאה? הפעל שוב את פקודות ה־chown למעלה.
    • Opensearch לא עולה? בדוק לוגים:

    sudo journalctl -u opensearch | tail -40
    * שגיאת SSL/Plugin? הוסף ל־opensearch.yml: plugins.security.disabled: true * Graylog נופל? בדוק לוג:

    sudo cat /var/log/graylog-server/server.log | tail -40
    * שגיאה על password_secret? ראה בהמשך.

    הגדרת סיסמאות מערכת (קריטי!)

    יצירת סוד מערכת:

    • הפק סיסמה חזקה:
    pwgen -N 1 -s 96
# העתק את הערך והדבק:
password_secret = <הסיסמה שיצרת>

    יצירת סיסמת admin מוצפנת:

    • הפק hash:
    echo -n 'סיסמה_חזקה_לבחירתך' | sha256sum
# העתק את ה-hash (רק המחרוזת) והדבק:
root_password_sha2 = <ה-hash>

    דוגמה:

    password_secret = FDSFAdjsf23ljlskjfdslkdfjksdfjksdfjksdfjkdsfjljsdfk
root_password_sha2 = e7cf3ef4f17c3999a94f2c6f612e8a888e5b06f27383bc499d1813fbbc11a046
# (שזו הסיסמה 123456 לבדיקות בלבד)
    • שמור את הקובץ והפעל:
    sudo systemctl restart graylog-server

    הגדרה ראשונית (Graylog 5 ומעלה)

    • בהפעלה ראשונה, יתכן ותראה בלוג:

    Initial configuration is accessible at ...
username 'admin' and password 'XXXXX' (סיסמה זמנית)
    * השתמש בסיסמה הזמנית לכניסה ראשונית דרך הדפדפן.

    מסך Certificate Authority (CA):

    • בהתקנה רגילה/בודדת – לחץ Create CA והמשך.
    • שלב Data Node – לחץ Skip provisioning אם אין לך אשכול (Cluster) של Graylog.

    פתיחת ממשק Web לכל הרשת

    • ערוך קובץ קונפיג:

    sudo nano /etc/graylog/server/server.conf
    * אתר שורה:

    http_bind_address = 0.0.0.0:9000
    * אם היה מוגדר 127.0.0.1 – שנה ל־0.0.0.0 או כתובת שרת. * הפעל מחדש:

    sudo systemctl restart graylog-server

    בדיקת תקינות שירותים

    • בדוק:
    systemctl status graylog-server opensearch mongod
sudo ss -tulnp | grep 9000
sudo netstat -tulnp | grep 9200

    טיפים לניקוי שאריות

    • ראה אילו שירותים/תהליכים פעילים:
    systemctl list-units --type=service | egrep 'graylog|opensearch|mongo'
ps aux | egrep 'graylog|opensearch|mongo' | grep -v grep
sudo dpkg -l | egrep 'graylog|opensearch|mongo'
sudo find /etc/ -type f \( -name "*.dpkg*" -o -name "*.bak" -o -name "*.save" \)
sudo du -sh /var/log/*
sudo apt autoremove --purge
sudo dpkg --configure -a
systemctl --failed

    שאלות ותשובות נפוצות

    למה צריך password_secret?

    משמש להצפנת מידע פנימי (sessions, tokens) – חובה בכל התקנה.

    מה הסיסמה הראשונית?

    ב־Graylog 5 – הסיסמה הראשונית מודפסת בלוג. אם הגדרת ידנית root_password_sha2 – זו הסיסמה.

    איך מחברים שרתי Windows?

    (הוספת input + התקנת NXLog/Winlogbeat – יפורט במדריך המשך)

    סיום

    Graylog רץ? פותח ממשק web? הצלחת לראות מסך התחברות? מצוין! אם יש בעיה, בדוק לוגים והגדרות לפי המדריך. בהצלחה 🚀
