    1. מבוא קצר

    Graylog היא מערכת קוד פתוח רבת עוצמה לאיסוף, עיבוד וניתוח לוגים בזמן אמת. מדריך זה מסביר כיצד להקים Graylog מאפס על גבי Ubuntu Server עדכני (22.04) ולחבר אליו שרתי Windows עם משלוח לוגים מסודר, כך שתוכל לראות ולנתח לוגים מכל הלקוחות במקום מרכזי.

    2. דרישות מוקדמות

    • שרת Ubuntu 22.04 (מומלץ מינימום 4GB RAM, עדיף 8GB+)
    • חיבור אינטרנט
    • הרשאות root או sudo
    • כתובת IP קבועה לשרת
    • פתיחת פורטים 9000 (ממשק ניהול), 12201/514 (לקבלת לוגים), 9200 (OpenSearch)
    • שרתי Windows 2012/2016/2019/2022

    3. הכנת שרת Ubuntu

    sudo apt update && sudo apt upgrade -y
sudo hostnamectl set-hostname graylog-server
sudo timedatectl set-timezone Asia/Jerusalem

    4. התקנת Java (נדרש עבור Graylog ו-OpenSearch)

    sudo apt install openjdk-17-jre-headless -y
java -version

    5. התקנת MongoDB (המאגר שמחזיק את הקונפיגורציות של Graylog)

    wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list
sudo apt update
sudo apt install -y mongodb-org
sudo systemctl enable mongod
sudo systemctl start mongod

    בדוק שהשירות רץ:

    sudo systemctl status mongod

    6. התקנת OpenSearch (תחליף ל-Elasticsearch)

    Graylog 5.0 ומעלה תומך רשמית ב-OpenSearch (העדפה על פני Elastic בגלל רישוי).

    wget -qO - https://artifacts.opensearch.org/publickeys/opensearch.pgp | sudo apt-key add -
echo "deb https://artifacts.opensearch.org/releases/bundle/opensearch/2.x/apt stable main" | sudo tee /etc/apt/sources.list.d/opensearch-2.x.list
sudo apt update
sudo apt install opensearch -y

    עריכת קובץ קונפיגורציה לשרת בודד:

    sudo nano /etc/opensearch/opensearch.yml

    הוסף/שנה את הערכים:

    network.host: 0.0.0.0
http.port: 9200
discovery.type: single-node

    הפעל והפעל אוטומטית:

    sudo systemctl daemon-reload
sudo systemctl enable opensearch
sudo systemctl start opensearch

    בדוק שהשירות רץ:

    curl -X GET "localhost:9200"

    7. התקנת Graylog

    הוספת מאגר וחבילת התקנה:

    wget https://packages.graylog2.org/repo/packages/graylog-5.2-repository_latest.deb
sudo dpkg -i graylog-5.2-repository_latest.deb
sudo apt update
sudo apt install graylog-server -y

    8. הגדרות ראשוניות של Graylog

    ערוך קובץ הקונפיגורציה הראשי:

    sudo nano /etc/graylog/server/server.conf

    הגדר:

    • password_secret: רצף תווים אקראי (מומלץ להפיק ב-bash: pwgen -N 1 -s 96)
    • root_password_sha2: הפק סיסמה ב-SHA256 (למשתמש admin):
    echo -n your_password | sha256sum
    • root_email: כתובת מייל שלך
    • http_bind_address: כתובת IP:9000 (לדוג' 0.0.0.0:9000 כדי לאפשר גישה מרשת)

    דוגמה:

    password_secret = <רצף ארוך>
root_password_sha2 = <הפלט מהפקודה לעיל>
root_email = admin@mydomain.com
http_bind_address = 0.0.0.0:9000

    9. פתיחת פורטים וחומת אש (UFW)

    sudo ufw allow 9000/tcp
sudo ufw allow 9200/tcp
sudo ufw allow 12201/udp
sudo ufw allow 514/tcp
sudo ufw enable

    10. הפעלת Graylog

    sudo systemctl daemon-reload
sudo systemctl enable graylog-server
sudo systemctl start graylog-server

    בדוק סטטוס:

    sudo systemctl status graylog-server

    11. גישה ראשונה לממשק וובי

    • גש עם דפדפן לכתובת: http://<IP של השרת>:9000
    • התחבר עם שם משתמש admin והסיסמה שהגדרת.

    12. יצירת Input לקבלת לוגים מ־Windows

    1. בממשק Graylog עבור ל־ System > Inputs
    2. בחר Input מסוג Syslog TCP (מומלץ ל־NXLog, לחלופין GELF TCP/UDP)
    3. בחר פורט (למשל 514 או 1514)
    4. לחץ Launch New Input והגדר שם, Bind address, הגבלות לפי הצורך
    5. הפעל את ה-Input

    13. התקנה והגדרת NXLog על שרת Windows

    13.1 הורדת NXLog

    • הורד את הגרסה החינמית (Community Edition) מהאתר: https://nxlog.co/products/nxlog-community-edition/download
    • התקן על כל שרת Windows שצריך לשלוח לוגים

    13.2 דוגמת קובץ קונפיגורציה ל-NXLog

    פתח את C:\Program Files\nxlog\conf\nxlog.conf וערוך (בצע גיבוי לפני!)

    דוגמה (Syslog TCP, כולל מזהה לקוח):

    define CUSTOMER CustomerA

<Input in>
    Module im_msvistalog
</Input>

<Output out>
    Module      om_tcp
    Host        <GRAYLOG_IP>
    Port        514
    Exec        $Message = '[CUSTOMER=' + string(CUSTOMER) + '] ' + $Message;
</Output>

<Route 1>
    Path in => out
</Route>

    הערות:

    • החלף <GRAYLOG_IP> בכתובת שרת ה־Graylog שלך
    • שנה את CUSTOMER לשם הלקוח/שרת (ClientA, ClientB, וכו')
    • אם יש כמה שרתים לאותו לקוח – תן לכל אחד שם אחר (ClientA-DC, ClientA-FS, וכו')
    • אם אתה רוצה לקבל לוגים ספציפיים – אפשר להגדיר זאת ב־Input.

    13.3 הפעל מחדש את NXLog:

    net stop nxlog
net start nxlog

    13.4 בדוק שהלוגים מגיעים ל־Graylog:

    • בממשק Graylog, חפש לפי שם הלקוח או השדה ששלחת

    14. Streams, חיתוך לוגים ודשבורדים לפי לקוח

    • ב־Graylog צור Stream לכל לקוח (System > Streams)
    • קבע כלל לזיהוי לוגים (לדוג' Message: contains "CUSTOMER=ClientA")
    • בנה דשבורד לכל לקוח/קבוצה
    • אתה יכול בקלות לבצע חיפושים לפי מזהה לקוח או שרת

    15. המלצות ובדיקות

    • ודא שכל השירותים (graylog, mongod, opensearch) פועלים
    • ודא שכל ה־Inputs פעילים
    • ב־Graylog – חפש אירועים לדוגמה כדי לאמת הגעת לוגים
    • ב־NXLog – בדוק קובץ לוג NXLog (לרוב ב־C:\Program Files\nxlog\data\nxlog.log) לאיתור תקלות

    16. קישורים שימושיים

    • אתר Graylog
    • דוקומנטציה רשמית
    • OpenSearch
    • MongoDB
    • NXLog

    הערות

    • לעומסים כבדים – הפעלת OpenSearch ו-MongoDB על שרתים ייעודיים.
    • הקפד לגבות את בסיסי הנתונים והגדרות השרת.
    • ניתן לשדרג את הקונפיגורציה (למשל, שימוש ב־GELF או TLS) לפי הצורך.
    • אתה יכול לנהל בקלות עד עשרות שרתים מממשק אחד.
