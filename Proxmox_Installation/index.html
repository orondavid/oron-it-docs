    מדריך התקנת Proxmox VE דרך HP iLO

    (התקנה מרחוק – ללא גישה פיזית לשרת)

    1. דרישות מקדימות

    חומרה

    • שרת HP עם iLO 4 / iLO 5
    • דיסק אחד לפחות (SSD / RAID)
    • חיבור רשת פעיל

    תוכנה

    • קובץ ISO של Proxmox VE
    • דפדפן תומך iLO (Chrome / Edge)

    2. הורדת קובץ ISO

    הורד את קובץ ההתקנה הרשמי של Proxmox VE ושמור אותו במחשב המקומי.

    3. התחברות ל־iLO

    גש לכתובת: 

    https://<ILO-IP>
    והתחבר עם משתמש בעל הרשאות Admin.

    4. חיבור ISO דרך Virtual Media

    Virtual Media → CD/DVD → Local ISO File
    בחר את קובץ ה־ISO ואשר חיבור.

    5. הגדרת Boot מה־ISO

    בצע Restart לשרת ובחר: 

    Boot Menu (F11) → Virtual CD/DVD

    6. התחלת התקנה

    בחר: 

    Install Proxmox VE
    ואשר תנאי רישוי.

    7. בחירת דיסק ואחסון

    • Ext4 – מומלץ לרוב המקרים
    • ZFS – רק אם יש ידע וזיכרון RAM מספק

    8. הגדרות אזור

    בחר: - Country - Timezone - Keyboard

    9. סיסמת Root ודוא"ל

    הגדר סיסמה חזקה והזן כתובת דוא"ל להתראות.

    10. הגדרות רשת

    • כתובת IP סטטית
    • Gateway
    • DNS
    • Hostname מלא (FQDN)

    11. התקנה

    אשר את הסיכום והמתן לסיום ההתקנה.

    12. ניתוק ISO ואתחול

    נתק את ה־ISO מ־iLO והמתן ל־Reboot.

    13. כניסה לממשק הניהול

    https://<Proxmox-IP>:8006
    משתמש: root

    14. פעולות לאחר התקנה

    ביטול Enterprise Repo

    sed -i 's/^deb/#deb/' /etc/apt/sources.list.d/pve-enterprise.list

    הוספת Community Repo

    echo "deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription" > /etc/apt/sources.list.d/pve-no-subscription.list

    עדכון מערכת

    apt update && apt full-upgrade -y

    15. בדיקות תקינות

    • גישה ל־Web UI
    • זיהוי דיסקים
    • רשת פעילה
    • זמן ותאריך תקינים

    סיכום

    השרת מוכן ליצירת מכונות וירטואליות, Cluster וגיבויים.
