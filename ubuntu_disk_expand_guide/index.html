    הרחבת נפח דיסק בלינוקס (Ubuntu + LVM + ext4)

    מדריך זה מציג תהליך מסודר, בטוח וברור להרחבת נפח דיסק
    בשרת Ubuntu שרץ על מכונה וירטואלית (VMware),
    כאשר מערכת האחסון מבוססת LVM ומערכת הקבצים היא ext4.

    המדריך כולל בדיקת החלטה מובנית האם נדרש להשתמש ב־growpart או לא.

    מומלץ לבצע Snapshot / גיבוי לפני עבודה בסביבת Production.

    מבנה כללי (לשם הבנה)

    VMware Disk (VMDK)
   ↓
Partition (sda3)
   ↓
Physical Volume (PV)
   ↓
Volume Group (VG)
   ↓
Logical Volume (LV)
   ↓
Filesystem (ext4)

    שלב 1 – הגדלת הדיסק בצד VMware

    מטרה: הגדלת הדיסק הווירטואלי (VMDK).

    1. כבה את ה־VM. (לא חייב)
    2. Edit Settings → Hard Disk.
    3. הגדל את נפח הדיסק (לדוגמה מ־50GB ל־100GB).
    4. שמור והפעל את ה־VM.

    בשלב זה רק הדיסק גדל. לינוקס עדיין לא משתמש בנפח החדש.

    שלב 2 – בדיקת מצב קיים בלינוקס

    lsblk

    בודקים: - גודל הדיסק (/dev/sda) - גודל המחיצה האחרונה (/dev/sda3)

    df -h

    מציג את הנפח הזמין בפועל (צפוי להישאר בגודל הישן).

    שלב 3 – בדיקת צורך בהרחבת מחיצה (growpart)

    מצב א' – אין צורך ב־growpart

    sda     100G
└─sda3   96.9G

    פירוש: - הדיסק גדל - המחיצה כבר תופסת כמעט את כל הדיסק

    ➡️ אין צורך להרחיב מחיצה.
    ניתן לדלג לשלב 4 (pvresize).

    מצב ב' – נדרש growpart

    sda     100G
└─sda3   48G

    פירוש: - הדיסק גדל - המחיצה נשארה בגודל הישן - קיים שטח לא מנוצל

    ➡️ יש להרחיב את המחיצה לפני המשך עבודה.

    3.1 התקנת הכלי (אם נדרש)

    sudo apt update
sudo apt install -y cloud-guest-utils

    מתקין את הכלי growpart.

    3.2 הרחבת המחיצה

    sudo growpart /dev/sda 3

    מרחיב את המחיצה /dev/sda3 כך שתנצל את כל הדיסק.

    בדיקה: 

    lsblk

    שלב 4 – הרחבת Physical Volume (PV)

    sudo pvresize /dev/sda3

    מעדכן את LVM שיש יותר שטח פיזי במחיצה.

    בדיקה: 

    sudo pvs

    עמודת PFree מציינת שטח פנוי ב־Volume Group.

    שלב 5 – הרחבת Logical Volume (LV)

    sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv

    מקצה את כל השטח הפנוי ב־VG ל־Logical Volume של /.

    בדיקה: 

    sudo lvs

    שלב 6 – הרחבת מערכת הקבצים (ext4)

    בדיקת סוג מערכת הקבצים

    lsblk -f

    יש לוודא שמערכת הקבצים היא ext4.

    הרחבת מערכת הקבצים

    sudo resize2fs /dev/ubuntu-vg/ubuntu-lv

    מרחיב את ext4 על כל נפח ה־LV החדש
    (Online – ללא ריסטארט).

    שלב 7 – אימות סופי

    df -h /

    יש לוודא: - שה־/ בגודל החדש - שקיים נפח פנוי בהתאם

    תקלות נפוצות

    • אין PFree אחרי pvresize
      → המחיצה לא הורחבה (בדוק שלב 3).

    • resize2fs נכשל
      → בדוק שסוג מערכת הקבצים הוא ext4
      (ב־XFS משתמשים ב־xfs_growfs).

    סיכום זרימת עבודה

    VMware → Disk
Linux  → Partition (אופציונלי growpart)
LVM    → PV → VG → LV
FS     → ext4 resize
